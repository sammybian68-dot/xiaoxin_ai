        小新用哪个模型

        打字和语音对话都用这里选的。选好马上生效，正在自由对话的话下一句起换。

        对话

        每个功能一个 md，在 server/prompts/，按顺序拼成 system prompt（不随时间变，前缀缓存一直命中）。时间、闹钟状态作为 [system] 消息插在对话里。改完跑一次部署。

        唤醒和主动退出时小新说的话叫醒时说「我在的」，说退出词或点挂断时说「拜拜」，用的是当前音色。换音色后自动跟着换

        唤醒词

        pad 开着「待命」时，本机一直听，一句话以其中任意一个开头就叫醒小新，后面可以直接接问题（「小新同学，现在几点」）。没叫醒时不上传、不花钱。每个至少 4 个字。* 代表任意一个字：「你好小*」能叫醒「你好小婷」「你好小嗯」这种认偏的。

        毫秒

        退出词

        通话中，一句话正好是其中任意一个（不能多一个字），就立刻挂断回待命，在 pad 本机判断，不等云端。「你先退下吧」这种不算。和唤醒词一样，「小新」被认成「小心」也算。

        端侧模型调试

        点开始后对着 pad 说话，每句话显示本机模型的转写（去掉标点，和匹配唤醒词、退出词时用的是同一串）。断句用上面的「待命时停多久算一句」。只在本机听，不连云端、不会真的唤醒；调试时待命暂停，停止后恢复。

          小新用哪个声音

          点哪个音色，「语音对话」里的朗读引擎就跟着切过去。CosyVoice 用内置男声，或者下面自己录的声音；豆包有一整排云端音色。▶ 是试听。

          爸爸妈妈的声音

          家长发给孩子的消息，在孩子的 pad 上用这里选的声音读出来。只列管理台注册过的家长；选「小新的声音」就和小新一样。

          添加豆包音色 ID

          列表里没有你想要的（比如「桃子」），就去火山引擎控制台「豆包语音 → 音色列表」复制那个音色 ID 填进来。加之前会先试合成一句，确认能用。
