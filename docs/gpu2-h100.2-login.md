# gpu2 和 H100.2 登录

下次要登这两台，先读这份。不要重新猜端口，不要把 H100.1 和 H100.2 混用。

记录日期：2026-10-26。从这台 Mac 实测过：`ssh gpu2` 免密通，再到 `ssh-h100.2 --check` 通。

更长的禁令和模型路径在 gpu2 上：`/Data/cmbian/codes/carHer2/docs/GPU_servers/README.md`。登录本身以本文为准。

## 先分清

| 名称 | 是哪台 | 从这台 Mac 怎么登 |
|---|---|---|
| **gpu2** | A100 工作站，控制面。不是 H100。`carHer2`、`mainbrain_27B_model` 在这台 | `ssh gpu2` |
| **H100.2** | 8×H100 80GB，主机名 `h100-11`，公网直连 | 先上 gpu2，再 `ssh-h100.2` |
| H100.1 | JumpServer 那台（`36.151.241.10`）。**不要用本文登** | 不在这里 |

这台 Mac 的 `~/.ssh/config` 只有 `gpu2`，没有 `h100.2`。不要在 Mac 上直接 `ssh h100.2`。

```
Host gpu2
    HostName 47.116.13.227
    Port 6001
    User cmbian

```

```bash
ssh gpu2
ssh gpu2 'hostname; nvidia-smi -L'
```

## H100.2

只从 gpu2 登。gpu2 上已免密。

```bash
ssh gpu2
/home/cmbian/bin/ssh-h100.2 --check          # hostname、whoami、nvidia-smi -L
/home/cmbian/bin/ssh-h100.2 'nvidia-smi'     # 一条命令
ssh h100.2                                   # 在 gpu2 上的别名，交互
```

非交互可以从 Mac 一条打过去：

```bash
ssh -o BatchMode=yes gpu2 '/home/cmbian/bin/ssh-h100.2 --check'
```

| 项 | 值 |
|---|---|
| SSH | `117.157.77.4:50011` |
| 用户 | `testh100` |
| 密钥 | gpu2 的 `~/.ssh/id_ed25519`，已写入远端 `authorized_keys` |
| 密码 | 不写进仓库。在 gpu2 的 `~/.carher2/h100.2_ssh`（权限 600），`sshpass -f` 直接读这个文件 |
| gpu2 上的别名 | `h100.2`、`h100-new` |
| 公网 HTTP | `http://117.157.77.4:50080` → 机内 `10.127.11.11:8000` |
| 主机名 | `h100-11` |

免密失败才用密码，且要在 gpu2 上（这台 Mac 没有 `sshpass` 配置，也不该绕过 gpu2）：

```bash
sshpass -f ~/.carher2/h100.2_ssh \
  ssh -o StrictHostKeyChecking=accept-new -p 50011 testh100@117.157.77.4 'hostname'
```

### 不要打这些

| 错误入口 | 原因 |
|---|---|
| `117.157.77.4:22` | SSH 在 **50011**，22 会拒绝或超时 |
| `117.157.77.4:8000` | 外网没有 8000，只有 **50080** |
| `36.151.241.10` | 那是 H100.1 |
| 在 Mac 上 `ssh h100.2` | 别名只写在 gpu2 的 `~/.ssh/config` |

模型占卡会变。登录后看 `nvidia-smi` 和 `docker ps`，不要沿用旧清单。2026-10-26 当时：GPU0+1 是 Qwen3.8-27B，GPU3 有 Qwen3.5-9B，35B-A3B 没在跑，GPU5–7 空。
