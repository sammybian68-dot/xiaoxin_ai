### 发现：BF16 版的专家是合并存的

FP8 版是逐专家存的：`mlp.experts.<i>.gate_proj` / `up_proj` / `down_proj`，每层 256 组。BF16 版和 transformers 5.x 把它们合并成每层两个 3D 参数：

| 参数 | 形状 |
|:--|:--|
| `mlp.experts.gate_up_proj` | [256, 1024, 2048] |
| `mlp.experts.down_proj` | [256, 2048, 512] |
| `mlp.gate.weight`（router，`Qwen3_5MoeTopKRouter`，不是 Linear） | [256, 2048] |
| `mlp.shared_expert_gate`（Linear 2048→1） | [1, 2048] |

所以路由专家不是 `nn.Linear`，`target_modules` 和 `all-linear` 都挂不到它们。要用 peft 的 `target_parameters`。

### LoRA 配置实测

在 meta 设备上用 peft 0.20.0 试了下面这份配置（没有占卡）：

```python
lang = r"model\.language_model\.layers\.\d+\."
LoraConfig(
    r=16, lora_alpha=32, lora_dropout=0.0,
    target_modules=lang + r"(self_attn\.(q_proj|k_proj|v_proj|o_proj)"
                        r"|linear_attn\.(in_proj_qkv|in_proj_a|in_proj_b|in_proj_z|out_proj)"
                        r"|mlp\.shared_expert\.(gate_proj|up_proj|down_proj))",
    target_parameters=["mlp.experts.gate_up_proj", "mlp.experts.down_proj"],
)
```

结果：

- 挂上的：10 层 attention 的 q/k/v/o，30 层 DeltaNet 的 5 个投影，40 层路由专家的两个 3D 参数，40 层 shared expert 的 3 个投影。
- 可训练参数里没有 router、`shared_expert_gate`、视觉塔、MTP。
- 可训练参数 9.44 亿，占总参数 36.05B 的 2.6%。大头是路由专家：peft 给每个专家各配一份 rank 16，所以 `lora_A` 的第一维是 16×256=4096，每层约 2300 万。

只试了 `lora_dropout=0.0`。peft 对 `target_parameters` 是否支持 dropout 还没验证。
