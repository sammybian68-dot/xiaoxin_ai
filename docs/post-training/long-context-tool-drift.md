# 长上下文工具调用漂移：后训练怎么治

长对话里工具调用开始飘、或者前面错一次后面一直错时，先读这份。内容来自 2026-10-29 的讨论，**都没有实测过**。基座、LoRA 挂层、mask、DPO 规则沿用 [qwen36-35b-a3b.md](qwen36-35b-a3b.md)，本文只写长上下文要额外做的事。

## 0. 结论

| 问题 | 结论 |
|:--|:--|
| 先做什么 | 位置扫描评测（§2），分清是长度漂移还是错误自我强化 |
| 长度漂移 | 用真实长轨迹做 SFT，监督点均匀落在各长度段，混回短数据 |
| 错误自我强化 | 在历史里注入错误调用，错误那轮不算 loss，只训纠正那轮。重点做「静默错误」 |
| DPO | 在长前缀上用 SFT 检查点自己采样，rejected 选照抄前文错误的那条 |
| RL | 根治 exposure bias 的办法，这一期不做 |
| 推理侧 | 约束解码兜住格式。改 prompt 或折叠历史要同步改训练数据 |
| router | 照旧冻住，aux loss 设 0。路由体检要分长度段 |
| 只能做一项数据 | 错误注入加静默错误 |

## 1. 两种问题

| | 长度漂移 | 错误自我强化 |
|:--|:--|:--|
| 现象 | 干净历史下，越长越容易错格式、错参数 | 前面有一次错误调用，后面照着错 |
| 原因 | 工具 schema 在系统提示开头，到 32k 离当前位置很远，取不回来 | 上下文里的错误调用被当成 few-shot 示范。SFT 只见过干净轨迹，没见过自己犯错以后怎么办（exposure bias） |
| 主要手段 | 长轨迹 SFT（§4） | 错误注入（§5）、on-policy DPO（§6） |

35B-A3B 的结构可能让长度漂移更明显：40 层里 30 层是 Gated DeltaNet，状态大小固定，靠衰减来忘，远处的细节只能靠那 10 层普通 attention 精确取回。这是推测，要靠 §2 的数据确认。

## 2. 先体检：位置扫描

同一批任务，把要考的那次工具调用放到不同长度处，每个长度再配几种历史：

| 维度 | 取值 |
|:--|:--|
| 长度段 | 4k、8k、16k、32k，模型撑得住再加 48k |
| 历史 | 干净；前面错 1 次；前面连错 3 次；静默错误（错了但没报错，见 §5） |
| 填充 | carHer2 的真实会话和工具返回，不要用无关文本凑长度 |

指标：

| 指标 | 含义 |
|:--|:--|
| 协议可解析率 | tool_call 能不能解析 |
| 工具选对、参数对 | 和金标比 |
| 纠错率 | 前面有错时，这一轮调对的比例 |
| 照抄率 | 这一轮复现了前文同一种错误的比例 |

怎么读：干净历史下随长度下降，是长度漂移；只在有错误历史时下降、照抄率高，是错误自我强化。两种都有就两边都做。

零样本基座和每个检查点都跑一遍，和 [qwen36-35b-a3b.md](qwen36-35b-a3b.md) §8 的行为评测放在一起。

## 3. 开训前查三件事

1. **序列长度。** 现在的起步超参是 6144（[qwen36-35b-a3b.md](qwen36-35b-a3b.md) §5.1），模型在 SFT 里从没在 32k 处做过工具调用。长轨迹要单独开一档，长度至少覆盖到要考的最长段。超长样本不要截断尾部，宁可丢掉，截断会切掉监督点。
2. **位置编码。** 看基座 `config.json` 里的 `max_position_embeddings` 和 `rope_scaling`，训练、评测、vLLM 线上三处要一致。线上开了 YaRN、训练没开，32k 的表现就对不上。
3. **显存。** 32k 一条，8 卡 ZeRO-3 加梯度检查点可能不够，需要序列并行或把 micro batch 降到 1。先用 10 条最长的样本跑一次 smoke 看峰值。没测过。

## 4. 长度漂移：长轨迹 SFT

### 4.1 轨迹从哪来

- 用 carHer2 线上代码生成的真实多轮会话拼长，规则同 [qwen36-35b-a3b.md](qwen36-35b-a3b.md) §2.2，不能自己拼 wire。
- 长度要来自真实内容：长工具返回（POI 列表、路线、搜索结果）、多段子任务切换、用户中途改主意。
- 不要拿无关文章或重复对话凑长度。模型会学到「前面都是噪声」，反而更不看前文。

### 4.2 监督点放哪

现有规则是只有最后一轮 assistant 算 loss（[qwen36-35b-a3b.md](qwen36-35b-a3b.md) §3.3）。长轨迹照用这条规则，办法是从同一条轨迹按不同位置截出多条样本，每条的最后一轮就是一个监督点：

```text
一条 40k 的轨迹 → 截在 6k / 15k / 24k / 33k 处 → 4 条样本，各自只训最后一轮
```

- 监督点在各长度段大致均匀，不要都落在开头。
- 优先截在「需要回看远处信息」的轮次：调用要用到很早之前的工具返回、地址、用户偏好。只用最近一轮信息就能答对的样本，练不到长上下文。
- 同一条轨迹截出的样本放在同一个 split，不要跨训练集和评测集。

### 4.3 配比

- 长样本占工具类数据的 20% 到 30% 起步，其余保持原来的短数据。只喂长样本，短上下文和口播风格会退。
- 每个长度段设下限，否则 32k 段的样本最容易被采样稀释。
- 起步值，以 §2 的曲线为准调。

## 5. 错误自我强化：错误注入

### 5.1 怎么造

在历史里放一次或几次错误的 assistant 调用，接真实或模拟的环境返回，然后是要训的那一轮，金标是正确调用。

| 类型 | 历史里的错误 | 环境返回 | 金标 |
|:--|:--|:--|:--|
| 显式报错 | 参数名写错、少必填参数、JSON 不闭合、调用不存在的工具 | 报错信息 | 按 schema 改正后重调 |
| 静默错误 | 用了旧版参数格式、单位错、选错了工具但碰巧返回了东西 | 看起来正常 | 按 schema 调对，不沿用前文写法 |
| 连错 | 同一种错连续 2 到 5 次 | 每次都报错 | 停下照 schema 改，或者换工具，或者向用户说明 |

静默错误最关键。它专门教模型「以 schema 为准，不以上下文里的先例为准」，对的就是「前面错了后面一直错」。

错误要像模型自己会犯的：最好从 35B 基座或 SFT 检查点在长前缀上采出的真实错误里挑，再补人工规则造的。人工造的错误太整齐，模型很快就学会识别它们，换成自己的错误就不管用了。

### 5.2 mask

- 历史里的错误调用一律 -100，不算 loss。算了就是在教它犯错。
- 只训纠正的那一轮。用 §4.2 的截法，这条规则自然满足。
- 抽几条样本打出 label 不为 -100 的 token，确认里面没有错误调用。

### 5.3 比例

- 注入样本占工具类数据的 10% 到 30%。
- 太多会让模型对正常历史也起疑，比如前文调对了还要换个写法再调一次。评测里要有「历史全对」的对照组，看这类误伤。
- 起步值，以 §2 的照抄率和干净历史的分数一起调。

## 6. DPO：在长前缀上采对子

门禁和采样规则照 [qwen36-35b-a3b.md](qwen36-35b-a3b.md) §6，长上下文只多两条：

1. 前缀里包括长历史和 §5 那样的错误历史，用 SFT 检查点在这些前缀上采样。
2. 优先配「对的调用 vs 照抄前文错误的调用」。两条都是模型自己采出来的，rejected 才是真实的失败模式，比人工造的有效。

长前缀上 DPO 很贵：prompt 不算 loss，但每对都要前向整个前缀。前缀相同的几条采样尽量放在同一个 batch，能复用 prefix 的话复用。

## 7. RL：这一期不做

多轮 agent RL 用可验证的奖励（协议可解析、执行成功、任务完成），模型在自己生成的轨迹上学，是根治 exposure bias 的办法，也可以单独奖励「出错后恢复」。但它要一套能跑工具的环境和长 rollout，代价高。SFT 加 DPO 后 §2 的纠错率还上不去，再考虑。

## 8. 推理侧

| 做法 | 作用 | 注意 |
|:--|:--|:--|
| 约束解码（vLLM 的 JSON schema / guided decoding） | 格式错误基本消除 | 只管格式，管不了选错工具、填错参数 |
| 在上下文末尾再放一份精简工具列表 | 缓解 schema 离得太远 | 改的是 wire，训练数据要按同样方式生成，不然训推不一致 |
| 折叠历史：失败的调用和长工具返回做摘要 | 错误先例不留在上下文里 | 同上，要在 carHer2 里实现，训练数据跟着改 |

后两项都会改线上 prompt。carHer2 不动，就不要只在训练里做。

## 9. router

照 [qwen36-35b-a3b.md](qwen36-35b-a3b.md) §4 冻住，aux loss 设 0。长上下文漂移出在取信息（attention、DeltaNet）和数据分布上，不是派给哪个专家的问题，训 router 帮不上忙。

路由体检（同上 §8.3）多加一个维度：按 §2 的长度段分别统计。长样本加进来以后，某个长度段单独变窄，就是这一档数据太窄，按 [qwen36-35b-a3b.md](qwen36-35b-a3b.md) §11 的办法反查。
